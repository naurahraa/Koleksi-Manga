# Aplikasi Koleksi Manga

Aplikasi Koleksi Manga adalah aplikasi berbasis web yang digunakan untuk mencatat dan mengelola koleksi manga secara digital. Pengguna dapat menambahkan data manga, memperbarui informasi, menghapus data, serta melihat koleksi secara keseluruhan melalui tabel interaktif.

Aplikasi ini dibangun sebagai implementasi materi praktikum Pemrograman Web, khususnya penerapan konsep CRUD (Create, Read, Update, Delete) menggunakan PHP, MySQL, JavaScript, HTML, dan CSS.
